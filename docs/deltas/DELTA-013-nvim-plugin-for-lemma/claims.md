- `lemma refs --json <file>` lists every `@ref`, `@per` and doc id in the doc with kind, line and column span, raw text and status.
- A ref's status in `lemma refs --json` is the diagnostic `evidence::resolve` gives, the same text lint reports for that ref when the doc is in lint's base range.
- A resolving ref with a symbol targets the symbol's first line; without a symbol, line 1.
- A doc id is a configured type prefix, `-` and digits, outside `[...]`; rule ids and claim ids are not listed as doc ids.
- A doc id targets that doc's `index.md` line 1; a configured prefix with no such doc has status `unknown`.
- `lemma refs --json` exits 0 when it prints the listing, whatever the entries' status, and exits 2 on a missing file or a file outside the lazyspec root.
- `lemma refs <claim>` output is unchanged.
- In a markdown buffer under a lazyspec root, claim ids, struck ids, directives and their targets, `[intent]`/`[proposed]` markers, `> review:` lines and doc ids with a pack prefix get their `Lemma*` highlight group.
- Markdown buffers outside a lazyspec root get no lemma highlights.
- Highlighting works with no `lemma` binary on `PATH`.
- Every `Lemma*` group is a default link to a standard group, so a user's highlight overrides it.
- Highlights follow edits to the buffer.
- `<Plug>(lemma-jump)` on a resolving ref opens the target file at the target line.
- `<Plug>(lemma-jump)` on a doc id opens that doc.
- `<Plug>(lemma-jump)` on an unresolved ref notifies lemma's diagnostic and does not move.
- `<Plug>(lemma-jump)` with no ref or doc id under the cursor runs builtin `gd` and does not call `lemma`, with or without the binary on `PATH`.
- `<Plug>(lemma-jump)` on a ref in a modified buffer warns to save first and does not move.
- With no `lemma` on `PATH`, the first jump on a ref or doc id notifies once and later jumps on refs or doc ids do nothing.
- When `lemma --version` differs from the plugin version, the first jump warns once and still jumps.
- The plugin installs with lazy.nvim from this repository and the README shows the spec. [intent]
- The pack's four parts carry one version. [intent]
